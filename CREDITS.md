## Replacing the photography

Replace the files in `public/images` with the salon's own photographs, keeping
the same aspect ratios, then update the `alt` text and dimensions in
`src/config/businessConfig.js`. If you prefer a different source set, edit the
`SLOTS` map in `scripts/build-images.mjs` and run:

```bash
node scripts/build-images.mjs
```

`sharp` is included as a dev dependency only; it is not shipped to the browser.
